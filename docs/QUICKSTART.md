# JARVIS CommerceOS 실행 가이드

이 문서는 **Docker를 처음 사용하는 사람도 CommerceOS를 로컬에서 실행할 수 있도록** 작성했습니다. CommerceOS는 개인 개발·테스트 용도로 먼저 확인하세요. 외부 판매 채널이나 AI API를 연결하지 않아도 대시보드와 기본 업무 흐름을 살펴볼 수 있습니다.

## 시작 전에 확인할 것

| 필요한 것 | 이유 | 확인 방법 |
| --- | --- | --- |
| Docker Desktop | 데이터베이스, API, 대시보드를 함께 실행합니다. | Docker Desktop을 열고 엔진이 실행 중인지 확인합니다. |
| 인터넷 연결 | 첫 실행 시 필요한 컨테이너 이미지를 내려받습니다. | 브라우저에서 일반 웹페이지가 열리는지 확인합니다. |
| 프로젝트 폴더 | 실행 파일과 기본 설정 파일이 있는 폴더입니다. | `README.md`, `start.sh`, `start.bat`, `docker-compose.yml`이 보이면 맞습니다. |

## 실행하기

### Windows

Docker Desktop을 먼저 실행합니다. 상태가 준비되면 프로젝트 폴더에서 `start.bat`를 더블클릭하세요. 검은 창에 서비스 로그가 표시되면 정상입니다. 첫 실행은 컨테이너 이미지를 준비하므로 시간이 걸릴 수 있습니다.

### macOS 또는 Linux

Docker Desktop 또는 Docker Engine을 실행한 뒤, 터미널에서 프로젝트 폴더로 이동하여 아래 명령을 한 줄씩 실행하세요.

```bash
chmod +x start.sh
./start.sh
```

## 브라우저에서 열기

실행 창을 닫지 않은 상태에서 `http://127.0.0.1:3000`을 엽니다. 이 주소가 운영 대시보드입니다. 서비스가 아직 준비되지 않았으면 잠시 기다린 뒤 브라우저를 새로고침하세요.

| 주소 | 용도 |
| --- | --- |
| `http://127.0.0.1:3000` | 운영 대시보드 |
| `http://127.0.0.1:8001/docs` | API 문서 (개발자용) |
| `http://127.0.0.1:8001/health` | 서비스 상태 확인 |

## 첫 로그인과 첫 작업

처음 로컬에서 실행할 때는 아래 기본 계정을 사용합니다.

| 입력 항목 | 값 |
| --- | --- |
| 이메일 | `admin@jarvis.example.com` |
| 비밀번호 | `change-me-now` |

이 계정은 로컬 개발용 초기 계정입니다. 외부에서 접근할 수 있는 환경으로 배포하거나 다른 사람과 공유하기 전에는 계정 정보와 비밀 설정을 변경하세요.

로그인한 뒤에는 아래 순서로 한 기능만 체험해 보세요.

| 순서 | 메뉴 | 해볼 일 |
| --- | --- | --- |
| 1 | `상품 후보 찾기` | 키워드를 입력하고 분석된 후보를 저장합니다. |
| 2 | `수익성 점검` | 저장한 후보의 마진과 예산 기준을 확인합니다. |
| 3 | `판매 준비` | 필요한 정보와 승인 준비 상태를 확인합니다. |

외부 판매 채널 등록, 가격·재고 변경은 사용자의 명시적 승인 전에 실행되지 않습니다.

## 종료와 다시 시작

서비스를 종료하려면 실행 중인 창에서 `Ctrl+C`를 누르세요. 다음에도 같은 `start` 파일을 실행하면 됩니다. `start` 파일은 `.env`가 없을 때만 `.env.example`을 복사하므로, 이미 만들어진 설정과 데이터는 일반 실행으로 덮어쓰지 않습니다.

> **주의:** `docker compose down -v`는 데이터 볼륨을 삭제할 수 있습니다. 단순히 종료하고 싶을 때는 사용하지 마세요.

## 문제가 생겼을 때

| 증상 | 원인일 수 있는 것 | 해결 방법 |
| --- | --- | --- |
| Docker 관련 오류가 보입니다. | Docker Desktop이 실행되지 않았습니다. | Docker Desktop을 열고 엔진 준비가 끝난 뒤 `start` 파일을 다시 실행하세요. |
| `3000` 또는 `8001` 포트가 이미 사용 중입니다. | 같은 서비스를 이전에 실행했거나 다른 앱이 포트를 사용합니다. | 이전 실행 창에서 `Ctrl+C`를 누른 뒤 다시 실행하세요. |
| 브라우저에서 페이지가 열리지 않습니다. | 서비스가 아직 준비 중이거나 실행 창이 닫혔습니다. | 실행 창의 오류를 확인하고, 잠시 기다린 뒤 `http://127.0.0.1:3000`을 다시 여세요. |
| 로그인에 실패합니다. | 기본 계정을 잘못 입력했거나 API가 아직 준비되지 않았습니다. | 이메일·비밀번호를 다시 확인하고, 실행 로그에 오류가 없는지 확인하세요. |
| 처음 실행이 오래 걸립니다. | 이미지와 패키지를 내려받는 중입니다. | 인터넷 연결을 확인하고 실행 창을 닫지 않은 채 완료될 때까지 기다리세요. |

스테이징 배포가 필요할 때만 README의 Render 배포 섹션과 `docs/DEPLOY_RENDER.md`를 참고하세요.
